# Generated artifacts

Sample output from the app, committed so a reviewer can open it without running anything. Both files come from a run of scenario A in `docs/08-DEMO-SCENARIOS.md` over the files in `samples/`, copied here from the app's own `generated/` folder:

- `northwind-q3-review.pptx`, the client deck: native, editable charts and speaker notes on every slide.
- `northwind-campaign-metrics.xlsx`, the metrics workbook: Summary, Recommendations, Data, Calculations and Sources sheets, with live formulas in Calculations.

Each one is meant to make sense to someone who has not seen the conversation that produced it. Every number in them traces back to an evidence entry, listed in the workbook's Sources sheet and named in a source footer on the deck's slides.
